# 隐私与证据政策

## 默认私有

以下内容默认不发布、不提交 Git、不写入公开日志：原始简历和论文、电话、个人邮箱、精确地址、头像、签名、身份证件、微信二维码、腾讯云环境标识、兑换码、Cookie、密码与云 API 密钥。

仓库的 `.gitignore` 排除 `private/`、`input/`、`generated/`、`.env*`、密钥文件与 ZIP。自动扫描会阻止私钥和常见云密钥模式；普通个人字段即使被允许，也必须出现在上传前披露中。

## 字段级同意

网站内容按字段选择发布。一次上传前的披露至少包含：

- 公开字段名与准确值；
- 公开头像、二维码及其他个人文件的准确路径；
- 本次确认仅适用于紧接着的一次上传。

之前说过“可以继续”或“以后不用问”不替代发布个人信息时的即时确认。用户可以删除任一字段后重新构建。

## 证据边界

每个项目事实保存来源。候选人的“设计与仿真”不会扩写为“制造、整机装配或投产”；参考论文作者的成果不会转移给候选人；没有来源的指标、奖项、Top 排名、性能提升和独立负责表述会被删除或标为待确认。

技术图片只允许基于明确坐标裁切，不做生成式伪造或无损放大承诺。论文截图应只保留图本身，排除正文、页眉页脚、页码和“图 4-2”等论文编号。

## 云端边界

部署仅支持腾讯云 CloudBase 静态托管。插件使用用户现有登录会话，不索要凭据。任何价格、套餐、续费或权限变化都需要新的明确授权。CI 永远不执行真实云端部署。
